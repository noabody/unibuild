ChtrFmtr Qt 6 port
==================

This is a monolithic Qt 6 Widgets port of the supplied Avalonia Program.cs.
The application is built from main.cpp; there are no .ui files and no extra
runtime libraries beyond Qt 6 Widgets and Qt 6 XML.

CMake (recommended)
-------------------
1. Install Qt 6 with the Desktop C++ kit for your operating system.
2. Open a terminal in this folder.
3. Run:
     cmake -S . -B build -DCMAKE_POLICY_VERSION_MINIMUM=3.5
     cmake --build build --config Release
4. Run the resulting ChtrFmtr executable from build/ (or build/Release on
   multi-configuration generators).

qmake
-----
1. Install Qt 6 and make sure qmake6/qmake is on PATH.
2. Run:
     qmake ChtrFmtr.pro
     make
   On Windows with MinGW use mingw32-make; with MSVC use the generated
   Visual Studio build files.

Notes
-----
- The port uses Qt Widgets, QFileDialog, QMessageBox, QRegularExpression,
  QDomDocument, QFile and QDataStream equivalents for the Avalonia/.NET APIs.
- The parser, importers, exporters, Game Genie conversion, group editing,
  dirty-state handling and activity log remain in one main.cpp as requested.
- Qt's native file dialogs are used instead of Avalonia StorageProvider.
- Binary formats are written little-endian to match .NET BinaryWriter behavior.
- The System Activity Log is a wrapping QPlainTextEdit so long messages wrap
  with the window instead of running off the right edge.
